# P1-life-insurance-sql-analytics
This is a practical Life Insurance SQL Analytics Project with a PAS database, a realistic insurance dataset, and 300 SQL questions covering Basic, Intermediate, and Advanced SQL. It is designed for SQL practice, Data Analyst preparation, and Life Insurance domain analysis.

🚀 SQL Portfolio Project – Life Insurance Analytics
I recently built an end-to-end Life Insurance Database & SQL Analytics Project using MySQL and MySQL Workbench.
This is a practical Life Insurance SQL Analytics Project with a PAS database, a realistic insurance dataset, and 300 SQL questions covering Basic, Intermediate, and Advanced SQL. It is designed for SQL practice, Data Analyst preparation, and Life Insurance domain analysis. I created this project specifically for some of my LinkedIn connections who requested a practical SQL project. They have basic and theoretical knowledge of SQL, but they don't have an actual dataset on which they can practice SQL extensively.

The main purpose of this project is to help SQL beginners who want to upgrade their skills and gradually progress to an advanced level. This project provides an end-to-end data analysis environment, where I have created the database, created the required tables, and inserted the data into those tables.

I have divided the project into three main steps:

Step 1 – Creating the Database
In the first step, we created a database named PAS (Policy Administrative System).

Step 2 – Creating Tables
In the second step, we created several tables, such as:
🔹 Customer 🔹 Policy 🔹 Agent 🔹 Branch 🔹 Premium Payment 🔹 Claims 🔹 Nominee

Step 3 – Inserting Data into the Tables
we inserted data into each table according to its structure and purpose.

These three steps together help us create the complete database environment.

I have provided the complete project materials You can download the project files which  including the database scripts, data, questions, solutions, and other project materials.

You simply need to copy the queries from GitHub or download the project files , paste the queries into MySQL Workbench, read each comment carefully, and run the queries step by step.
Once you complete these steps, your database will be created with all the required tables and data. This completes the raw data creation stage.
Now, we need to practice SQL on this database, and that is the main reason I created this project.
I have noticed that many people have theoretical knowledge of SQL but lack practical experience in working with actual datasets and solving business-related problems.
Therefore, I have created 300 SQL questions related to this Life Insurance database, along with the SQL code that can be used to solve them. I have also provided the expected answers and outputs so that you can practice independently and validate your results.
Through these exercises, you can learn how SQL can be used for:
📊 Data Analysis – Extract, filter, summarize, and analyze data to answer business questions.
📈 Identifying Trends – Analyze policy sales, premium collections, claims, customer activity, and other insurance-related metrics over time.
🔍 Understanding Patterns – Identify customer behavior, policy patterns, payment trends, claim patterns, and other important insights hidden within the data.
💡 Business Problem Solving – Use SQL to convert business requirements into meaningful queries and analytical outputs.
🧹 Data Handling – Learn how to work with NULL values, duplicate records, different data types, dates, strings, and missing information.
🔗 Working with Relational Data – Understand how multiple tables can be connected and analyzed using different types of JOINs.
📌 Advanced Data Analysis – Use CTEs, subqueries, aggregate functions, CASE statements, and Window Functions to perform more advanced analysis.
🎯 Real-World Business Data – Gain practical experience working with a structured dataset that represents a Life Insurance business environment rather than practicing only on simple sample tables.
This will help you strengthen your DQL (Data Query Language) skills and give you practical experience with SQL commands.
The objective is not just to learn how to write a SQL query, but to understand why the query is required, what business problem it solves, and how the output can be interpreted.
If you face any difficulty while working on this project, feel free to leave a comment or send me a direct message. I will be happy to help.
One important requirement for this project is that you should have a basic understanding of SQL. If you do not have basic knowledge of SQL queries and SQL concepts, it may be difficult to understand the dataset and complete the exercises in the intended way.
So, I recommend having a basic understanding of SQL before starting this project.
I hope this project helps SQL learners and aspiring Data Analysts gain practical experience with SQL and Life Insurance data analytics.
